# Agents: Writing Usage Guidance

`docs/` contains installation and usage guidance for Photographers and their Agents. Follow the repository-wide context and artifact rules in [`../AGENTS.md`](../AGENTS.md).

- Before changing a guide, use the [`specs/` index](../specs/README.md) to read the behavior, design, and specialist contracts that govern its workflow.
- Explain the steps a reader performs and the observable result of each step. Keep commands and examples checkable against the governing contracts.
- Link to authoritative contracts for requirements, command syntax, and technical boundaries. Change those contracts under [`../specs/AGENTS.md`](../specs/AGENTS.md) when a workflow needs new behavior.
- Keep the [guidance index](README.md) focused on usage and installation guides and the specifications index.
